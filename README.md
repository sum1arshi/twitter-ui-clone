# Twitter Clone

A responsive Twitter (X) clone built with Tailwind CSS featuring a modern UI inspired by the official X platform.

## Features

- Responsive Twitter-inspired UI
- Tailwind CSS styling
- Mobile-friendly design
- Sidebar navigation
- Feed layout
- Trending section

## Technologies Used

- HTML5
- Tailwind CSS

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/sum1arshi/twitter-ui-clone.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser.
